# Personal Portal

A personal project archive to store and organize links to mini projects and websites in one easily accessible place.

## Purpose

Untuk mengarsip dan menyimpan tautan tautan mini proyek atau proyek website yang sudah dibuat, agar mudah diakses dan tidak hilang.

## Tech Stack

- HTML
- CSS
- JavaScript

## Features

- Store and organize project links
- Easy access to all mini projects and websites
- Simple and OG clean interface
